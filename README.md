# 🔋 ChargeRL: 사용자 패턴 기반 배터리 수명 보호 강화학습 시뮬레이션

본 프로젝트는 스마트기기 사용자의 불규칙한 충전 패턴을 학습하여, **배터리 노화(Aging)를 최소화**하고 **사용자 편의성(완충 상태 확보)**을 동시에 달성하기 위한 AI 에이전트 시뮬레이션입니다. Q-Learning 알고리즘을 활용하여 기존의 즉시 충전(Greedy) 방식이나 단순 예측(EMA) 방식을 뛰어넘는 최적의 충전 스케줄링을 제안합니다.

## 1. 연구 배경 및 목적
대부분의 사용자는 취침 시 충전기를 연결하고 아침에 분리합니다. 배터리가 100%에 도달한 후 장시간 고전압 상태로 방치되면 화학적 노화가 가속화됩니다. 
본 연구는 강화학습을 통해 기기 해제 시점을 능동적으로 예측하고, **기기 해제 직전에 충전이 100%에 도달하도록 유도하는 최적 대기 시점**을 도출하여 배터리 수명(SoH)을 보호합니다.

## 2. 핵심 기술적 특징

### 2.1 UX 중심의 보상 설계 (UX-Aware Reward Shaping)
단순 수치 최적화가 아닌 사용자 경험(UX)을 최우선으로 고려했습니다.
- **Grace Period (유예 시간):** 완충 후 30분 이내에 기기를 해제하면 방치 페널티를 부여하지 않아 현실적인 사용자 패턴을 수용합니다.
- **가혹한 미완충 페널티:** 사용자가 기기를 들었을 때 완충이 안 되어 있는 상황을 방지하기 위해, 기기 해제 시점의 SoC가 99.5% 미만일 경우 강력한 페널티를 부여합니다.

### 2.2 고도화된 상태 공간 정의 및 시뮬레이션 (State Quantization)
- **15분 단위 Step 진행:** 에피소드의 시간 축을 15분 단위로 압축(Quantization)하여 Q-Table의 희소성(Sparsity) 문제를 해결하고 수렴 속도를 극대화했습니다.
- **다양한 기상 패턴 (Wake-up Distribution):** 평일과 주말의 기상 분포(정규 분포)를 다르게 적용하여 현실적인 환경을 구축했습니다.

### 2.3 환경 급변에 대한 자율 적응 로직 (Robustness to Lifestyle Shifts)
- **Phase Shift 대응 (`train_2case.py`):** 사용자의 라이프스타일이 급변하여 기상 시간이 3시간 이상 지연되는 상황을 가정합니다.
- **에이전트 자율 감지:** 물리적 지표(최근 50번의 평균 방치 시간 및 SoC)를 모니터링하다가 패턴 변화를 감지하면, 에이전트가 스스로 탐험율(Epsilon)을 강제 부스팅하여 새로운 환경에 재수렴합니다.

## 3. 파일 구조 및 설명
- `env.py`: 충전 시나리오 및 보상 함수가 정의된 환경 (기본 / 환경 급변 케이스)
- `agent.py`: 상태 양자화 및 Q-Table 기반의 행동(대기/충전)을 결정하는 Q-Learning 에이전트
- `train.py`: 알고리즘 학습 및 기본 결과 그래프(Reward, Aging, Trade-off, Boxplot) 도출

## 4. 시뮬레이션 결과 요약

본 시뮬레이션은 제안 기법인 **Q-Learning**과 베이스라인인 **Predictive ML (EMA 모델)**, **Greedy (즉시 충전)** 3가지 정책을 비교합니다.

| 비교 항목 | Greedy (즉시 충전) | Predictive ML (EMA 기반) | Q-Learning (Proposed AI) |
| :--- | :--- | :--- | :--- |
| **배터리 보호** | 최악 (방치 시간 매우 김) | 보통 (안전 마진으로 인한 방치) | **최상 (해제 직전 완충 수렴)** |
| **완충 안정성** | 높음 | 중간 (불규칙한 패턴에 취약) | **매우 높음 (수렴 후 안정화)** |
| **환경 변화 적응** | 불가 | 느림 (이동평균 지연 발생) | **즉각적 (자율 탐험 부스팅)** |
